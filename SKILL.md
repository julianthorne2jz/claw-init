# claw-init

Project scaffolder for agents

## Usage

```bash
claw-init [options]
```

## Options

- `--watch`
- `--description`
- `--author`
- `--github`
- `-g`
- `-d`
- `-a`

## When to Use

Use this tool when you need to project scaffolder for agents.

## Notes

- Run `claw-init --help` for full usage information
